# Transferência internacional

mecanismo_vigente: nenhum

A API em produção citada em `docs/CLOUD_LOGGING_MOBILE.md` está em Cloud Run `us-central1`. O ledger de custo do projeto aponta a mesma região. Dado pessoal sensível tratado fora do Brasil precisa de uma hipótese do art. 33. Este repositório não tem cláusulas, decisão de adequação, garantia específica nem consentimento destacado para a transferência.

O que fecharia este item é migrar o tratamento para `southamerica-east1` (São Paulo) ou registrar um instrumento do art. 33 que a direção tenha de fato adotado. Trocar o texto deste arquivo sem uma dessas duas coisas não muda a situação.

Não há, hoje, base para marcar a transferência como resolvida.
