description Guia de Integração de Wearables de Pulso

Esta API recebe dados biométricos em tempo real de smartwatches e smartbands de pulso (Apple Watch, Galaxy Watch, Fitbit, Pixel Watch, Garmin), aplica filtragem física de ruído (BMO / Oscilação Média Limitada), infere dados fantasmas (Pressão Arterial, Oxigenação, Glicose e Tônus Vagal) e gera alertas clínicos instantâneos.

open_in_new Abrir Swagger OpenAPI (/docs)

api Endpoints da API REST & WebSocket

POST /api/v1/wearables/ingest Ingestão individual de leitura de wearable de pulso

Recebe telemetria de pulso (BPM, HRV, Temp, SpO2, Sinal PPG bruto) e retorna a análise completa com dados fantasmas e diagnósticos.

POST /api/v1/wearables/batch-ingest Ingestão em lote de leituras acumuladas

Sincroniza múltiplos registros de leituras acumuladas offline por dispositivos no pulso dos pacientes.

GET /api/v1/wearables/patient/{patient_id}/latest Obtém a última leitura e estado do paciente

Retorna o estado fisiológico mais recente e as estimativas de pressão arterial e glicose inferidas.

POST /api/v1/signal/bmo-analysis Análise de Oscilação Média Limitada (BMO / VMO)

Analisa o perfil de oscilação multiescala e norma BMO de um sinal de pulso bruto (PPG).

WS /ws/telemetry?api_key={key} Stream contínuo de telemetria em tempo real

Canal de WebSocket para transmissão ao vivo dos dados processados diretamente para dashboards e centrais médicas.
